# motivation_app_data

Данные для приложения [motivation_app](https://github.com/AndreyFrigoris/motivation_app): цитаты в формате JSON. Приложение при старте загружает файлы отсюда и кэширует их локально.

## Структура

В папке **`data/`** лежат JSON-файлы:

| Файл | Описание |
|------|----------|
| `quotes_main.json` | Лента цитат (EN) |
| `quotes_main_ua.json` | Лента цитат (UK) |
| `quotes_main_ru.json` | Лента цитат (RU) |
| `quotes_noty.json` | Короткие цитаты для уведомлений (EN) |
| `quotes_noty_ua.json` | Короткие цитаты для уведомлений (UK) |
| `quotes_noty_ru.json` | Короткие цитаты для уведомлений (RU) |

**`quotes_main*`** — массив объектов:

- `text` — текст цитаты
- `author` — автор или источник

**`quotes_noty*`** — объект `{ "messages": [ "...", ... ] }`: короткие строки для ежедневных уведомлений («краткая мотивация»), не смешанные в ленту.

Сейчас в приложении используется **одна лента** (`quotes_main*`). Отдельные категории (стоики, юмор, кино/аниме и т.д.) отложены; при появлении категорий сюда добавятся отдельные файлы (или подпапки).

## Как приложение использует данные

Приложение запрашивает файлы по адресу:

`https://raw.githubusercontent.com/AndreyFrigoris/motivation_app_data/master/data/<имя_файла>`

При каждом запуске кэш обновляется из этого репозитория; при отсутствии сети используются данные, встроенные в приложение (assets).

## Источник и лицензия

Часть базы цитат основана на репозитории [micheleriva/the-quotes-database](https://github.com/micheleriva/the-quotes-database) (автор: Michele Riva), который распространяется по лицензии **MIT**.

В этом репозитории данные дополнительно отредактированы: выполнены отбор, удаление дублей, структурные правки и локализация (включая переводы).
